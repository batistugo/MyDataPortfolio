Avaliação da Eficácia da Terapia com Hormônio do Crescimento no Tratamento de Crianças com Baixa Estatura Idiopática e Pequenas para a Idade Gestacional

Hugo Batista da Silva

Sobre o projeto

A cliente deste projeto me procurou para analisar dados do SUS (Sistema Único de Saúde) que dariam suporte à sua dissertação de mestrado em farmácia. Por causa da pandemia e de dificuldades pessoais, o projeto ficou parado por dois anos, o que tornou necessária a contratação de um cientista de dados.

Os dados se referem a um tratamento com injeções de hormônio do crescimento oferecido pelo governo a crianças com baixa estatura idiopática (BEI) e a crianças pequenas para a idade gestacional (PIG). O tratamento consiste na aplicação de quatro injeções ao longo de quatro anos (uma por ano), e a altura da criança é medida e comparada com a altura média esperada para a sua idade, conforme definido pela Organização Mundial da Saúde (OMS).

O objetivo inicial era reproduzir os dados de evolução da altura ao longo das aplicações com base nos dados oficiais da OMS. No entanto, apesar de se tratar de um estudo censitário, a coorte era pequena. Por isso, depois das análises descritivas e dos estudos iniciais, foi ajustado um modelo de regressão linear utilizando dois indicadores construídos para o estudo.

As conclusões finais não foram incluídas neste documento, pois o estudo também serviu de base para possíveis mudanças na política de tratamento hormonal. O objetivo deste documento é apresentar a análise exploratória e mostrar como os estudos foram definidos.

A base de dados

A base bruta contém 22 variáveis, mas, após a análise, apenas 8 delas serão utilizadas. As variáveis incluídas na análise são sexo, diagnóstico (BEI ou PIG), idade no início do tratamento, altura no início do tratamento e altura após 1, 2, 3 e 4 anos de tratamento. A altura está expressa em escore-z, que indica o desvio em relação à altura ideal de cada criança (sendo 0 o escore-z ideal). Esse cálculo foi feito com o software da OMS.

Descrição dos dados, gráficos e testes

Antes de iniciar a análise descritiva, foi necessário criar variáveis categóricas para sexo e idade. Como não havia uma variável adequada para ser a resposta do modelo de regressão, foram criadas duas variáveis indicadoras adicionais: “tratamento” e “diferenca”.

A variável “diferenca” foi criada para ser a variável resposta do modelo de regressão. Ela representa a diferença entre a altura inicial da criança, registrada antes do início do tratamento, e a altura mais recente disponível após o início do tratamento.

A variável “tratamento” assume os valores discretos 1, 2, 3 e 4, em que “1” representa a conclusão de um único ciclo de tratamento, “2” a conclusão de dois ciclos, e assim por diante até “4”. A inclusão de “tratamento” como covariável no modelo final permitiu investigar a relação entre a evolução da altura dos pacientes e a sua adesão ao tratamento.

Testes

Para avaliar se a altura mudou de forma significativa após um ano de tratamento, comparamos a altura inicial de cada criança com a altura da mesma criança após um ano. Como as duas medidas vêm dos mesmos indivíduos, as amostras não são independentes e o teste adequado é o teste t pareado, que trabalha com a diferença dentro de cada criança:

\[D_i = \text{HAZ}_{1,i} - \text{HAZ}_{0,i}\]

As hipóteses do teste t pareado são:

\(H_0: \mu_D = 0\) (não há mudança média na altura após um ano).

\(H_1: \mu_D \neq 0\) (há mudança média na altura após um ano).

O pressuposto de normalidade do teste t pareado se refere às diferenças \(D_i\), e não às colunas originais de altura; por isso, é essa a variável que testamos. Para os testes de normalidade a seguir, as hipóteses são:

\(H_0 =\) As diferenças seguem uma distribuição normal.

\(H_1 =\) As diferenças não seguem uma distribuição normal.

Teste de normalidade

library(nortest)
dif_1 <- dataset$HAZ_1ANOS - dataset$HAZ_INÍCIO

t1 <- lillie.test(dif_1) # Lilliefors (KS with estimated mean and sd)
t2 <- cvm.test(dif_1) # Cramer-von Mises
t3 <- ad.test(dif_1) # Anderson-Darling
t4 <- shapiro.test(dif_1) # Shapiro-Wilk

# Result Table
testes <- c(t1$method, t2$method, t3$method, t4$method)
estt <- as.numeric(c(t1$statistic, t2$statistic, t3$statistic, t4$statistic))
pvalue <- c(t1$p.value, t2$p.value, t3$p.value, t4$p.value)
results <- cbind(estt, pvalue)
rownames(results) <- testes
colnames(results) <- tr(c("Statistics", "p-value"), c("Estatística", "p-valor"))
print(results, digits = 4)
                                               Estatística   p-valor
Lilliefors (Kolmogorov-Smirnov) normality test     0.07536 2.359e-03
Cramer-von Mises normality test                    0.31508 2.201e-04
Anderson-Darling normality test                    1.79086 1.360e-04
Shapiro-Wilk normality test                        0.95821 2.204e-06

Todos os testes rejeitam a hipótese nula ao nível de 5%, ou seja, as diferenças não seguem exatamente uma distribuição normal. (O teste de Kolmogorov-Smirnov tradicional não foi usado porque ele não é válido quando a média e o desvio padrão são estimados a partir dos próprios dados; o teste de Lilliefors é a versão corrigida.)

Isso não invalida o teste t pareado neste caso: com pelo menos 54 crianças em cada grupo, o Teorema Central do Limite garante que a média amostral das diferenças tem distribuição aproximadamente normal, e é nisso que o teste de fato se apoia. Mesmo assim, como verificação de robustez, apresentamos também o teste de Wilcoxon (postos sinalizados), a alternativa não paramétrica para dados pareados, que não pressupõe normalidade.

Testes pareados por grupo

Para não repetir o mesmo código para cada variável, uma função auxiliar aplica os dois testes em cada nível de uma variável de agrupamento:

paired_tests <- function(data, group_var) {
  results <- data[, {
    tt <- t.test(HAZ_1ANOS, HAZ_INÍCIO, paired = TRUE)

Conclusão

Com todos os pressupostos verificados e o modelo validado, podemos interpretar os coeficientes e fazer inferências a partir do modelo. O modelo final é:

\[Y = 0.4777 + 0.2547X_1 - 0.198X_2 - 0.0422X_3 + 0.2422X_4 - 0.1499X_5\]

Variável Descrição
Y Diferença entre a altura inicial da criança e a altura mais recente disponível após o início do tratamento.
X1 Número de tratamentos
X2 Altura em escore-z no início do tratamento
X3 Idade em anos no início do tratamento
X4 Sexo; 1 = masculino, 0 = feminino (referência)
X5 Diagnóstico; 1 = PIG, 0 = BEI (referência)

Cada coeficiente é interpretado mantendo as demais variáveis constantes. Sexo e diagnóstico são variáveis dummy, portanto seus coeficientes são medidos em relação a uma categoria de referência: meninas (X4 = 0) e BEI (X5 = 0).

O intercepto (0,4777) é a diferença esperada para uma menina com diagnóstico de BEI quando todas as variáveis numéricas valem zero (nenhum tratamento, escore-z inicial 0 e idade 0). Essa combinação não existe nos dados (todas as crianças receberam pelo menos um tratamento), então o intercepto funciona como ponto de ancoragem do modelo e não tem, isoladamente, interpretação prática direta.

A variável “número de tratamentos” é a que tem maior impacto sobre a diferença. Cada ano de tratamento hormonal aumenta a diferença em 0,2547, podendo chegar a 1,0188.

Para a variável “altura inicial”, quanto mais negativo o escore-z, maior a diferença ao final do tratamento. Ou seja, quanto menor a altura inicial da criança, maior a diferença final, com coeficiente de -0,198.

A variável “idade” funciona de forma parecida com a altura inicial, mas sempre “piora” a diferença, já que a idade é sempre positiva e o coeficiente é negativo. Concluímos que, quanto mais nova a criança, melhor o resultado, pois maior será a diferença.

Quanto ao sexo, os meninos respondem melhor ao tratamento: com o mesmo número de tratamentos, a mesma altura inicial, a mesma idade e o mesmo diagnóstico, a diferença esperada para um menino é 0,2422 de escore-z maior que a de uma menina. As meninas são a categoria de referência, por isso não há um coeficiente próprio para elas; o 0,2422 é a distância entre os dois grupos.

Por fim, as crianças com diagnóstico de PIG (Pequeno para a Idade Gestacional) têm diferença esperada 0,1499 de escore-z menor que as crianças com diagnóstico de BEI (Baixa Estatura Idiopática), mantidas as demais condições. Isso não significa que as crianças PIG pioram com o tratamento, apenas que ganham menos que crianças BEI comparáveis.

Concluímos que o cenário ideal para uma criança obter os melhores resultados é completar os 4 anos de tratamento, ter o menor escore-z de altura inicial possível, começar o tratamento o mais cedo possível, ser do sexo masculino e ter diagnóstico de BEI.
